Automação pessoal de desenvolvimento

PSE Remote Delivery Dev

Ferramenta pessoal para compilar e entregar atualizações do projeto PSE usando GitHub Actions e Google Drive. Não é um serviço aberto a cadastros.

Como funciona

Após uma revisão de desenvolvimento, a automação compila as versões Windows e Android, prepara os pacotes de código, Aplicador, Backup e Relatório, preserva os resultados no repositório privado do proprietário e copia os arquivos para a pasta configurada do projeto no Google Drive.

Acesso ao Google Drive

O proprietário autoriza sua própria conta Google. O acesso permite localizar as pastas existentes, publicar as entregas e ler os arquivos enviados para verificar sua integridade. A automação não depende de um computador pessoal ligado.

O OAuth solicita acesso amplo ao Drive para alcançar pastas preexistentes. A implementação restringe suas operações à raiz configurada do projeto e verifica os identificadores das pastas antes da publicação.

Esta página não recebe credenciais, não inicia autenticação e não oferece downloads de arquivos privados.
